# Dangote IT Portal

SPFx React starter for the Dangote Group IT Department homepage.

## Included
Responsive corporate dashboard shell: hero, quick links, announcements, project portfolio, KPI cards, resources, events, leadership and footer.

## Build
Use a supported Node.js LTS version for SPFx 1.24.1:
`npm install`, `gulp build`, `gulp bundle --ship`, `gulp package-solution --ship`.

Package output: `sharepoint/solution/dangote-it-portal.sppkg`.

Upload the package to the SharePoint App Catalog, deploy it, then add the Dangote IT Portal web part to the target modern page. This starter has not yet been built or tested in the target tenant.
